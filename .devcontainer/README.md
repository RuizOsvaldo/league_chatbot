# Dev Container Setup

This folder contains the VS Code Dev Container configuration for the LEAGUE Streamlit Course.

## Quick Setup

1. Install Docker Desktop
2. Install VS Code "Dev Containers" extension
3. Open this project in VS Code
4. Click "Reopen in Container" when prompted
5. Run: `streamlit run examples/day_1_example.py`

Your development environment will be automatically configured with all required packages.

> **Alternative:** Use GitHub Codespaces for cloud-based development without local Docker setup.

See [../DEVELOPMENT.md](../DEVELOPMENT.md) for detailed setup options.
